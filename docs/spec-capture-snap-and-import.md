# キャプチャ撮影：1枚撮影・停止と取り込みの分離 — 確定仕様（v1.0.10）

## 要望（2026-10-02）

- キャプチャ撮影に**1枚だけ撮る機能**を足したい。
- 録画の停止＝取り込み開始ではなく、**取り込みを始めるボタンを別に作り**、停止した後も**録画を再開できる**ようにしたい。

v1.0.9 までは、ガジェット（撮影中に画面の右上に出る小さな窓・`gadget.html`）の「■ 録画停止」を押すと、
①ガジェットが閉じ ②録画のまとまり（ピクチャ\CheckListMaker 内のセッションフォルダ）が確定し
③取り込みウィザードが自動で開いた（2-R4）。止めたら続きは撮れず、クリックせずに1枚撮る手段もなかった。

## 決定事項

### ユーザーの回答（AskUserQuestion）

| 論点 | 決定 |
|---|---|
| 1枚撮影の操作 | ガジェットの「📷 1枚撮影」ボタン と キーボードの **F9** キーの両方 |
| F9 の表示 | F9 が撮影キーであることをガジェットに明示する（ボタンにキーの形で「F9」を出す） |
| 取り込まずに ✕ で閉じたとき | **確認の窓**：「取り込む」「取り込まずに閉じる」「やめる」。1枚も撮っていなければ何も聞かずに閉じる |
| ガジェットの見た目 | モック `screenshots/v1.0.10-gadget-mock.png` で承認 |

### 開発側で決めたこと（計画の承認で合意）

- 再開したときの画像は**同じセッションフォルダに続き番号**で入る。取り込みは最後に1回でまとめて行う。
- セッションフォルダは「最初に録画を開始したとき」か「最初に1枚撮影したとき」に作る。
- 経過時間は録画中だけ進み、停止中は止まる。枚数はクリック撮影と1枚撮影の合計。
- 1枚撮影はガジェットが開いていればどの状態でも使える。撮るのは**マウスカーソルのあるモニタ全体**
  （ボタンで撮るとガジェットのあるモニタになる）。クリック位置の赤枠・拡大画像は付けない。手順文は空
  （取り込みウィザードで書く。フォルダから画像を取り込むときと同じ）。
- F9 は**ガジェットが開いている間だけ** Electron の `globalShortcut` で登録する。この間、ほかのアプリには F9 が届かない
  （Excel の再計算など）。登録できなければ（ほかのアプリが使用中）ガジェットに赤字で知らせ、ボタンで撮ってもらう。
  押しっぱなしの連射は 400ms 以内なら無視する。録画中も F9 自体は「キー操作の手順」として記録しない。
- 「取り込みへ進む」は1枚以上撮るまで押せない。録画中に押したら、録画を止めてから取り込みウィザードを開く。
- 本体のツールバー「キャプチャ撮影」ボタンは、録画中は「録画停止」（＝ガジェットの停止と同じ。取り込みは開かない）。
  ガジェットが開いている間は、本体の「画像インポート」ボタンを押せない（書きかけのセッションを取り込ませないため）。

## ガジェットの状態

| 状態 | 見出し | メインのボタン | 1枚撮影 / F9 | 取り込みへ進む |
|---|---|---|---|---|
| 録画準備（`ready`） | 録画準備 | ● 録画開始（緑） | 撮れる | 1枚以上撮っていれば押せる |
| 録画中（`recording`） | ● 録画中（赤い点が点滅） | ■ 録画停止（赤） | 撮れる | 押せる（0枚なら不可） |
| 録画停止中（`paused`） | ■ 録画停止中（灰色の四角） | ● 録画再開（緑） | 撮れる | 押せる |

```
本体「キャプチャ撮影」 → 録画準備 ─録画開始→ 録画中 ─録画停止→ 録画停止中 ─録画再開→ 録画中 …
                              │                 │                      │
                              └──── 1枚撮影 / F9 はどの状態でも撮れる ───┘
「取り込みへ進む」（どの状態からでも・1枚以上） → ガジェットを閉じる → 本体を前面へ → 取り込みウィザード
✕（1枚以上） → 確認の窓：取り込む ＝「取り込みへ進む」と同じ／取り込まずに閉じる ＝ 保存だけして閉じる／やめる ＝ 何もしない
✕（0枚） → そのまま閉じる（作りかけのセッションフォルダは空なので消す）
```

- 録画停止中はマウス・キーボードの監視（uiohook）と、クリック直前を撮る撮影プロセス（`capture.js`）を止める。
  ガジェットは閉じず、本体は最小化のまま、セッションは続く。
- 「取り込まずに閉じる」はセッションを確定（`session.json` の `endedAt` を記録）して本体を前面に戻し、
  トースト「撮った画像（N枚）を保存しました。「画像インポート」から取り込めます。」を出す。

## 1枚撮影の保存形式（サイドカー v5）

- 画像は従来どおり `NNN.png`（続き番号）。拡大画像 `NNNz.png` は作らない。
- サイドカー `NNN.json` の `kind` に **`"snap"`** を追加（`SIDECAR_VERSION` 4 → 5）。
  `text` は空文字、`click` の各値・`imagePoint` は null、`marker` は `{ drawn:false }`、`uia` は解決なしの雛形。
  `display`・`capture`（`source: 'grab'` か `'ondemand'`）は従来どおり。
- 取り込みウィザードでは、`snap` の手順に拡大／全景の切り替えを出さない（`kind:'file'` と同じ扱い）。既定は全景。

## IPC（main ⇔ レンダラー）

| チャンネル | 呼ぶ側 | 動き |
|---|---|---|
| `rec:start` | 本体 | ガジェットを開く（録画準備）。開いていれば前に出すだけ（従来どおり） |
| `rec:begin` | ガジェット | 録画開始・再開。戻り値 `{ ok, startTime, elapsedMs }` |
| `rec:pause` | ガジェット・本体 | 録画停止（ガジェットは閉じない）。旧 `rec:stop` は廃止 |
| `rec:snap` | ガジェット（F9 は main 内で直接） | 1枚撮影 |
| `rec:finish` | ガジェット | 取り込みへ進む |
| `rec:state`（main→本体） | — | `{ recording, active, count }`。`active` はガジェットが開いているか |
| `rec:done`（main→本体） | — | `{ dir, shots, import }`。`import:false` はウィザードを開かずトーストのみ |
| `gadget:state`（main→ガジェット） | — | `{ mode, elapsedMs, startTime }`。本体からの停止などをガジェットの表示へ反映 |

## 実装の場所

- `main.js`：`stopRecording` を `pauseRecording`（停止）と `finishSession({ importNow })`（終了）に分割。
  `startCapture` を開始・再開兼用に。`snapShot`（1枚撮影）を追加。F9 の登録・解除。ガジェットの `close` で確認の窓。
- `keys.js`：`SNAP_KEY`（`F9`・keycode 67）と `isSnapKey(e)`。main の登録と録画からの除外はこの定数を使う。
- `session.js`：`SIDECAR_VERSION = 5`。
- `preload.js`：`pauseRecording`・`snap`・`finishSession`・`onGadgetState`。`stopRecording` は `rec:pause` を呼ぶ。
- `gadget.html`：3状態・「1枚撮影 [F9]」・「取り込みへ進む」。窓の高さは 336 → 362px（Electron 31 で中身の下端 345px を実測）。
  赤字の警告が出たら main の `warnGadget` が窓を 60px 伸ばす（2行の警告で 54px。以前は警告が窓の下にはみ出していた）。
  描画の確認：`screenshots/v1.0.10-gadget-states.png`（録画準備・録画中・録画停止中・警告）。
- `index.html`：ツールバーのボタン・画像インポートボタンの無効化・`rec:done` の `import:false`・ウィザードの `snap`。

## 確認（実機）

録画（グローバルフック・F9・確認の窓）はユーザーの Windows 実機でしか通しで確かめられない。

1. 本体「キャプチャ撮影」→ ガジェット（録画準備）。F9 → 1枚目が撮れ、枚数 1・プレビューが出る。
2. 録画開始 → 他アプリを2回クリック（2・3枚目）→ 録画停止 → ガジェットは閉じず「録画停止中」・経過時間が止まる。
3. 停止中に F9 → 4枚目。録画再開 → クリック → 5枚目。経過時間は止めた所から続く。
4. 「取り込みへ進む」→ 本体が前面に出てウィザードが開き、1〜5 が1つのまとまりで並ぶ（1・4 は文が空・切り替えなし）。
5. もう一度ガジェットを開いて1枚撮り、✕ → 確認の窓。「取り込まずに閉じる」→ トースト。画像インポートの一覧に出る。
6. 録画中に F9 を押しても「F9 を押す」という手順は記録されない。
