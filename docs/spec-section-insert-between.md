# 仕様: セクションの間の「＋」でセクションを追加する

ユーザー要望（2026-09-11）。従来はツールバー右上の「セクションを追加」（テンプレート型は
「フェーズを追加」）ボタンで末尾に足すしかなかった。セクションとセクションの間に「＋」を置き、
その位置に挿入できるようにする。見た目は `screenshots/mock-section-add-{A,B,C,D}.png` の
4案から **D 案**をユーザーが選択。

## 見た目（D 案）

- **セクションの間**: 高さ 16px の空き（`.sec-gap`）。マウスを置くと**青い1本線**（`.sec-gap-line`）と
  中央の**丸い「＋」ボタン**（`.sec-add`・24px）が現れる。普段は何も見えない。
  ホバー中の＋は青地に白。キーボードで＋にフォーカスしたときも線と＋を出す（`:focus-visible`／
  `:focus-within`）。説明の吹き出しは出さない（`aria-label` のみ）。
- **末尾**: 幅いっぱい・高さ 40px の点線ゾーン `.sec-add-tail`「＋ セクションを追加」
  （テンプレート型は「＋ フェーズを追加」）。ホバーで青くなる。従来のボタンの `data-tip` を引き継ぐ。
- ツールバー右上の「セクションを追加／フェーズを追加」ボタンは**無くす**。「表紙を編集」は残る。
- `.sections` を縦の flex にし、`.section` の `margin-bottom` は 0（間隔は `.sec-gap` が担う）。

## 動作

- `M.addSection(checklist, title = '', index = null)`: `index` が整数ならその位置に挿入
  （0〜length にクランプ）。省略時は従来どおり末尾。既存の呼び出しは無変更で動く。
- クリックは `data-action="insert-section"`・`data-index="<挿入位置>"`。間の＋は「次のセクションの
  添字」、末尾は `sections.length`。追加後は `pendingFocusSection` でその見出し入力にフォーカスし、
  すぐ名前を打てる（項目の「ここに項目を追加」と同じ作法）。
- セクションの並べ替え（ドラッグ）は `.section` 要素だけを見るので `.sec-gap` の影響なし。
  印刷／PDF は `#app` ごと非表示なので紙面には出ない。
