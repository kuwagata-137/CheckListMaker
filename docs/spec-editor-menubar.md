# 仕様: エディタのメニューバーを横一列にする（＋ホバー解説・トップバーのアイコン）

ユーザー要望（2026-09-09）「実行や名前を付けて保存等の機能があるメニューバーは縦のスペースを
使い過ぎているので、横一列にまとめてください」を受けて、モックで合意してから確定した仕様。
対象は `index.html` の編集画面上部のみで、データ構造・出力（Word/Excel/PDF/HTML/共有リンク）の
中身は変更しない。

## 背景（変更前）

編集画面の上部は4段積みで、合計およそ 300px を縦に消費していた。

| 段 | 要素 | 高さの目安 |
| --- | --- | --- |
| 1 | `#topbar` | 約 46px |
| 2 | `.editor-head`（← 一覧・タイトル・バッジ） | 約 52px |
| 3 | `.editor-progress`（進捗バー） | 約 36px |
| 4 | `.editor-toolbar`（タブ＋パネル＋罫線＋固定列） | **約 163px** |

4段目は `flex-direction: column` で「タブ列 38 ＋ パネル 35 ＋ 罫線 1 ＋ 固定列 35 ＋
gap 36 ＋ margin-bottom 18」を積んでいた。

## 確定した決定事項

### 1. レイアウト（案B＝ドロップダウンに畳んで1行）

```
[ファイルで出力 ▾] [印刷] [作業を開始 ▾] [作業をリセット] ──── [フェーズを追加] [表紙を編集]

（2026-09-11 追記: 「フェーズを追加／セクションを追加」ボタンはツールバーから外し、セクションの
間の「＋」と末尾の追加ゾーンに置き換えた。`docs/spec-section-insert-between.md` 参照。）
```

- `.editor-toolbar` は `display: flex; gap: 8px; flex-wrap: wrap`。**縦に段を積まない**
  （狭いときだけ折り返す）。タブ（`.tb-tabs` / `.tb-tab` / `.tb-panel` / `.tb-divider` /
  `.tb-fixed`）と、選択中タブを保持していた `activeToolbarTab` は撤去した。
- 並び順はユーザー指定。指定の無かった編集系（`フェーズを追加` / `表紙を編集`）は
  `.tb-edit { margin-left: auto }` で右へ寄せる。

### 2. 表記（絵文字は全廃）

| 新しい表記 | 旧表記 | `data-action` |
| --- | --- | --- |
| ファイルで出力 ▾ | 📤 他ファイルで出力（タブ） | `menu-export`（ドロップダウン） |
| 印刷 | 🖨 印刷 | `print` |
| 作業を開始 ▾ | ▶ 実行（タブ＋ボタン） | `menu-run`（ドロップダウン） |
| 作業をリセット | ↺ 一括リセット | `reset` |
| フェーズを追加 | ＋ フェーズ | `add-section` |
| 表紙を編集 | 🪧 表紙 | `cover` |

- **絵文字は `.editor-toolbar` と2つのメニューから全廃**する。`#topbar` のアイコン
  （元に戻す・やり直す・キャプチャ撮影・画像インポート）は対象外（→ 4章）。
- ToDo 型は `表紙を編集` を出さず、`作業をリセット` の位置に `完了を削除`
  （`clear-completed`）を出す。`フェーズを追加` は `セクションを追加`。

### 3. ドロップダウンの中身

| メニュー | 項目 | `data-action` |
| --- | --- | --- |
| ファイルで出力 ▾ | 名前を付けて保存（HTML）／ Word (.docx) ／ Excel (.xlsx) ／ PDF ／ 共有リンク | `save-html` / `save-docx` / `save-xlsx` / `save-pdf` / `share` |
| 作業を開始 ▾ | 全画面で実行 ／ 小窓で実行 | `play` / `play-guide` |

- 実装は `.rb-palette`（リッチ本文のパレット）と同系の軽量ポップオーバー `#tb-menu`。
  項目は**既存の `data-action` をそのまま持つ**ので、委譲ハンドラの `switch (action)` は無変更。
- 閉じる契機は **外側の mousedown ／ Esc ／ 項目の選択 ／ 同じボタンの再クリック**。
- `z-index` は `#thumbs`(20) より上・`.player-overlay`(90) より下の **80**。
- **環境による出し分けは従来の条件を踏襲**（`guideAPI` / `docxAPI` / `xlsxAPI` / `printAPI`）。
  `小窓で実行` が無い環境（ブラウザ単体）では `作業を開始` を**ドロップダウンにせず
  `play` の直接ボタン**にする（項目1つのプルダウンを作らない）。
- `作業を開始` は項目0件のとき `disabled`（従来どおり）。
- 単体HTML（`IS_STANDALONE`）では `save-html` のラベルを「保存（HTML）」にする（従来どおり）。

## 4. ホバー／フォーカスで出る解説ポップ（`data-tip`）

- 説明文は **`data-tip` 属性**に持たせる。OS 標準の `title` は表示が遅く装飾も効かないため、
  `data-tip` を付けたボタンからは `title` を外す（アイコンのみのボタンには `aria-label` を残す）。
- `document` への委譲で `mouseover` / `focusin` を拾い、`#tip-host`（`position: fixed`）を
  1つだけ作って中身を差し替える。`mouseout` / `focusout` / `Esc` / クリック / スクロールで隠す。
  ホバーからの表示は **400ms 遅延**、フォーカスからは即時。
- 位置はボタンの直下中央、下にはみ出すときは上へ、左右は画面内に寄せる。
  `z-index` は `#tb-menu`(80) より上・`.player-overlay`(90) より下の **85**。
  `@media print` で非表示、`prefers-reduced-motion: reduce` でフェードを切る。
- 見た目は `--surface` ＋ `--border-strong` ＋ `--shadow`、角丸8px、幅上限 300px。
  1行目にボタン名（太字。`aria-label` → 表示文字の順で拾い、末尾の `▾` は落とす）、
  2行目に説明（`--muted`）。

| ボタン | 説明文 |
| --- | --- |
| 元に戻す | 直前の操作を取り消します（Ctrl+Z） |
| やり直す | 取り消した操作をやり直します（Ctrl+Y） |
| キャプチャ撮影 | 録画ガジェットを開きます。クリックするたびに画面を自動で撮影します |
| 画像インポート | 撮影した画像やフォルダ内の画像を、1枚＝1手順として取り込みます |
| ファイルで出力 | Word・Excel・PDF・HTML などのファイルに書き出します |
| 印刷 | 印刷プレビューを開きます。用紙サイズ・向き・倍率を指定できます |
| 作業を開始 | 手順を1つずつ大きく表示して、チェックを付けながら順番に進めます。全画面と、作業しながら見られる小窓のどちらかを選べます。（小窓が無い環境では「手順を1つずつ全画面で大きく表示して、チェックを付けながら順番に進めます。」） |
| 作業をリセット | すべてのチェックを外して、最初から実施できる状態に戻します |
| フェーズを追加 / セクションを追加 | 手順（項目）をまとめる区切りを末尾に追加します |
| 表紙を編集 | Word・PDF の先頭に付ける表紙を作成・編集します |
| 完了を削除（ToDo型） | チェック済みの項目をまとめて削除します |

`buildStandaloneHtml` は `<script>` 全体を埋め込むため、書き出した単体HTMLでもそのまま動く。

## 5. トップバーのアイコンの大きさと縦位置

- 原因は**アイコンの箱の高さが揃っていないこと**。録画はインライン SVG（20px）、他は
  `font-size: 1rem` の文字（行ボックス約24px）で、差の約4pxぶん録画ボタンだけ
  ラベルが上にずれていた。
- アイコンを `<span class="tb-ic">` で包み **`height: 28px` の flex 中央寄せ**にして、
  SVG と文字グリフの高さの差を吸収する。
- **キャプチャ撮影の SVG を 20 → 24px**、**画像インポートの `📥` を色つきインライン SVG
  （26px）に差し替える**。絵文字では「取り込み」が連想できないため、開いたフォルダの口から
  写真がのぞく図にした（20px の 1.3 倍＝26px）。録画アイコンと同じく**固定色**にして、
  ライト／ダークどちらの背景でも同じ見え方にする。
- `↶` `↷` は `1rem` のまま。`--topbar-h` は `syncTopbarHeight()` が実測するので、
  `.editor-head` の sticky 位置は自動で追従する。
- 単体HTML出力が書き出すトップバー定義（undo / redo のみ）にも `.tb-ic` と `data-tip` を同期する。

## 結果

`.editor-toolbar` の高さは **約163px → 40px**（実測・1440px 幅）。`#topbar` はアイコンの箱の
ぶん約4px 高くなるので、上部全体では **約100px の削減**。
